# Marca de Agua · v1.2.1

Añade un texto como marca de agua a varias fotos a la vez, con opacidad y posición a tu gusto.

- 100% local: las fotos nunca salen de tu navegador.
- Texto, tamaño, color, opacidad, posición y contorno personalizables.
- Descarga todo en un **ZIP** o foto por foto, conservando el formato original (JPG, PNG, WEBP).

## Uso

1. Abre `index.html` en tu navegador (doble clic) o con un servidor local.
2. Arrastra o selecciona tus fotos.
3. Escribe el texto, ajusta tamaño y color.
4. **Descargar ZIP**.

Requiere conexión a Internet solo para cargar `vendor/jszip.min.js`, que ya está incluido en la carpeta.

## Despliegue

Es una página estática: puede publicarse gratis en GitHub Pages (incluyendo la carpeta `vendor/`).
